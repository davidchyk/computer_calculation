Як користуватись

Кількість аргументів: Число, яке вказує на кількість унікальних аргументів, які приймає кожна перемикальна функція.

Елементарна основа: Пара значень, які визначають нормальну та операторні форми перемикальних функцій.

Ввід функції F (Режим "Ввід функції як набір"): Поле для вводу послідовності чисел.

Ввід функції F (Режим "Ввід функції як вираз"): Поле для вводу аналітичного запису функції.

Інше: Використовуйте кнопку "+" для додавання полів для вводу функцій та "-" — для їх видалення.
